# Commit Structure

## Types

- **fix**: Bug fixes
- **update**: Updates to existing features
- **feat**: New features
- **remove**: Removed features
- **refactor**: Code refactoring

## Format

branch: "branch name"
type: "Types"
file: "file name"
change: "change made"
type(file): change

## Example

branch: "feature/google-map"
fix(googleMap.tsx): Fixed address formatting issue.
